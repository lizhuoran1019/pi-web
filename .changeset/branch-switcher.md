See and move between the versions of a message you re-asked. Where a conversation forked, the message you sent now shows a `‹ 2/3 ›` counter, and the arrows show the branch on either side; the newest reply in that branch becomes the shown conversation. An arrow is unavailable at either end of the list, while the session is busy, and for a branch whose messages have not been answered yet. Switching no longer clears the prompt editor — nor does navigating to a reply from `/tree`, which used to discard whatever was typed.
